## 📖 Problem Statement

Implement the **Dictionary Abstract Data Type (ADT)** that supports the following operations:

* 🔍 Search
* ➕ Insert
* ❌ Delete
* ⬆️ Maximum
* ⬇️ Minimum
* ◀️ Predecessor
* ▶️ Successor

The objective is to implement these operations using different data structures and analyze their **worst-case time complexities**.

---

## 🎯 Objective

This assignment aims to:

* Understand the working of the **Dictionary ADT**.
* Implement all dictionary operations using different data structures.
* Compare the efficiency of different implementations.
* Analyze the worst-case time complexity of each operation.

## ⚙️ Dictionary Operations

| Operation      | Description                                                 |
| -------------- | ----------------------------------------------------------- |
| 🔍 Search      | Finds an element using its key.                             |
| ➕ Insert       | Inserts a new element into the dictionary.                  |
| ❌ Delete       | Removes an existing element from the dictionary.            |
| ⬆️ Maximum     | Returns the element with the largest key.                   |
| ⬇️ Minimum     | Returns the element with the smallest key.                  |
| ◀️ Predecessor | Returns the element immediately smaller than the given key. |
| ▶️ Successor   | Returns the element immediately larger than the given key.  |
